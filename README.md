# MKS Knowledge — 最小知识集

基于刘雪峰「最小知识集」理论的交互式 HTML 学习系统。

## 项目结构

```
项目名/
├── index.html                    ← 知识主板首页
├── 1-专题名.html                 ← 散件（电脑端）
├── ...
└── 项目名_全集_YYYYMMDD.html     ← 合并版（手机端）
```

- **散件**：各专题独立 HTML，电脑端通过首页链接导航
- **合并版**：单文件，手机端复习用（汉堡菜单 + 触控优化）

## 技术规格

- 纯 HTML/CSS/JS 单文件
- CSS 3D 翻转知识卡片
- SVG 概念关系图
- localStorage 持久化
- 暖色系 (#fdf6ec/#fffaf2/#c0392b/#3d2f2f)
- 响应式（桌面横向导航 + 手机汉堡菜单）
- 知识卡片移动端 ≤60% 视口高度

## 版本命名

合并版用 `_YYYYMMDD` 日期后缀。
