🌟 时代概览

v2.36 标志着 MKS Builder 从「知识提取工具」进化为「创意方法论平台」。 核心突破在于：不再满足于把知识「正确地呈现出来」，而是建立了一套 可复用的创作方法论——创意模式库（Creative Patterns Library，840 行 8 章）， 指导每个专题如何用不同的叙事方式、交互形式、视觉隐喻来呈现知识。 同时，多作者总导航页（Hub 模式）和跨课程 MKS 知识体系的建立，让平台从单兵作战升级为可以容纳多作者、多系列的创作生态。

🎨 创意模式库（Creative Patterns Library）

📚 840 行 · 8 章 · 可复用创作方法论

创意模式库是 v2.36 最核心的知识资产。它不是操作手册，而是创作方法论—— 告诉设计者「如何思考内容的呈现方式」，而非「按什么步骤操作」。8 章覆盖从设计哲学到具体技法的完整链路。

🎯 核心创意铁律

🚫 禁止卡片罗列

每个专题至少使用 4-6 种不同的内容呈现方式。不允许一个专题全是翻转卡片、或全是列表。多样性不是装饰——不同的知识类型需要不同的认知交互。

🧭 隐喻选择矩阵

7 种知识类型对应 7 种隐喻方向：

层级结构 → 金字塔 流程知识 → 河流/管道 对比知识 → 天平/镜像 演化知识 → 树/年轮 网络知识 → 星座/星系 工具知识 → 工具箱/瑞士军刀 叙事知识 → 旅程/地图

📖 5 大核心叙事模式

  • 层级递进 — 从基础到高阶
  • 旅程渐进 — 学习者的成长弧线
  • 解密戏剧 — 悬念→线索→揭示
  • 训练营闯关 — 挑战→练习→升级
  • 史书展开 — 时间线→事件→因果

🧰 13 种交互形式工具箱

  • 翻转卡片 / 拖拽排序 / 填空
  • 时间线滑块 / 对比滑块
  • 概念地图 / 嵌套展开
  • 场景决策树 / 角色扮演
  • 拼图匹配 / 渐进揭示 / 自由探索
  • 模拟沙盘

🎬 首页视觉图必须有叙事弧线

禁止教科书式图解——那是「解释」而非「邀请」。首页视觉图必须讲述一个有弧线的故事： 设问 → 探索 → 揭示。让学习者在进入内容之前就已经被叙事吸引。

🔑 放权比规范更出质量

设计师 brief 写愿景不写规范——告诉 Claude Code「我想让学习者感受到概念的层层递进」， 而不是「用 3 层嵌套列表+翻转卡片」。这是从 v2.20「目标导向 prompt」理念的进一步深化。

📐 数据 → 设计五步转化法

  1. 分析内容的知识类型
  2. 选择对应的隐喻方向
  3. 确定叙事模式
  4. 从工具箱中选择 4-6 种交互形式
  5. 设计首页叙事弧线
