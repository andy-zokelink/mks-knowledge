DeepSeek 10亿Token消耗事件

▼

AI整理知识库时进程死循环空转，两天烧掉了3000多元Token费用。从API调用日志逐层深入→发现进程异常→最终建立三道规则巡检体系（每小时检查进程，30分钟/1小时/24小时交叉告警）。

💡 教训：AI Agent 7×24自主运行需要watchdog，不能完全放任。三道巡检缺一不可。这个案例在7月1日讲座上被作为核心教训分享。
👻

Claude Code 僵尸进程

▼

一个Claude Code子进程持续运行了36天没被发现，静默消耗API费用。催生了进程巡检系统——每小时自动扫描所有相关进程，命中规则即推送飞书群告警。

💡 教训：从此再也没有"悄悄的烧钱"。每小时进程快照是最低配置。
🔑

GitHub Token 过期导致周报推送失败

▼

周日学术周报生成完毕、commit完成，但GitHub Pages推送静默失败——Token已过期数天未被发现。修复后建立推送后API验证机制：每次push后自动curl GitHub API确认远端文件存在。

💡 教训：推送≠成功。所有外部API调用必须加验证环节。
🔀

模型选择踩坑

▼

DeepSeek-V4-Pro的reasoning模式在cron job中导致stream超时（180秒无输出被杀连接），切换到V4-Flash解决。base_url残留导致API key打到错误的API端点（401/404错误）。

💡 教训：沉淀出模型切换三步验证法——新模型上线前必须通过cron兼容性测试、端点验证、stream超时测试。

  • 元宝（腾讯） — 录音整理、视频号分享整理。微信里分享的文章和视频，元宝可以帮你提取关键信息。

🔑 三个必须理解的关键概念

概念一：大模型本质是一个"压缩包"
— 借鉴 Andrej Karpathy（OpenAI联合创始人）的经典比喻

互联网上约 10TB 的文本 → 经过训练 → 变成约 140GB 的模型参数
压缩比约 100倍，但有损压缩——模型掌握了知识的"大概"，不是精确复制
就像你读完一本书后记住的是大意，而不是逐字背诵
概念二：参数 = 模型的"神经元"
• GPT-3：1750亿参数 ≈ 320GB存储空间
• GB数越大 ≈ 知识量越大、理解力越强
• 就像人脑神经元越多，处理复杂问题的能力越强
概念三：Token = AI的"字数"
• Token是模型理解和收费的基本单位
• 分词器将文本切成小块：可能是一个字、一个词、甚至标点符号
• 1个中文字 ≈ 1-2个token
• 类比：就像打车按公里计费，AI按token计费

为什么内存涨？AI硬件产业链

🔗 算力产业链全景

GPU→ HBM内存→ 光模块→ 散热→ 电力→ 数据中心

💡 核心逻辑链

① HBM是什么？ — AI芯片的"高速氧气管"。GPU没有HBM就是废铁，数据喂不进去。

② 供需严重失衡：三星/海力士/美光三家垄断全球93% HBM产能，2026年产能已被锁单至2028年。HBM良率仅50-60%（传统DRAM超90%）。

③ 成本占比飙升：HBM在AI芯片成本占比从52%升至63%。以英伟达B200为例，HBM成本占45%，远超GPU核心的14%。

④ 产能虹吸效应：存储厂将70-80%先进产能转向HBM → 挤压消费级内存 → 手机/电脑内存也跟着涨。

⑤ 后续逻辑：AI落地到终端设备 → 智能终端/消费电子需求暴涨 → 芯片+存储+传感器全链条受益。
