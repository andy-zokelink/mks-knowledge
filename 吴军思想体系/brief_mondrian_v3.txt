# Mondrian Blocks v3 — 脚本注入数据

## 你的任务
生成两个文件：
1. `mondrian_template.html` — HTML/CSS/JS 完整页面，数据用 `{{ENTITIES_JSON}}` 占位
2. Python 脚本注入 entities.json → mondrian_blocks.html

注入脚本同 Warhol v3 brief。

## 视觉效果
Mondrian《红黄蓝构图》：
- 红 #E3292E、黄 #F5D300、蓝 #0A4D9B、白 #FAFAFA、黑 #1A1A1A
- 不规则 CSS Grid（grid-template-areas 命名区域）
- 粗黑边框 6-8px（灵魂元素）
- 7 个类别各一个 Mondrian 色块，内部标签云排列
- 3-5 个焦点卡片特大尺寸
- hover 浮起，click 展开
- 移动端单列

## 验收
1. 注入脚本运行 → 生成 HTML
2. node -c 语法检查
3. 确认占位符已被替换
