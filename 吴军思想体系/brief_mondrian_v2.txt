## 视觉效果
Mondrian《红黄蓝构图》风格：
- **不规则网格**：用 CSS Grid 命名的 grid-template-areas 创造不对称布局
- **4 主色调**：红 #E3292E、黄 #F5D300、蓝 #0A4D9B、白 #FAFAFA
- **7 个大色块**：每个类别一个 Mondrian 矩形区域，内部排列该类别的实体（标签云风格）
- **粗黑边框**：6-8px solid #1A1A1A 分割线——这是灵魂
- **3-5 个焦点卡片**：挑最重要的实体（如"牛顿""爱因斯坦""工业革命""能量×信息"）做成特大色块
- hover 色块浮起，点击展开该类别的全量实体

## 技术要求
- 单文件 HTML，数据内嵌
- CSS Grid + named areas
- 默认视图：~15-20 个大色块
- 点击后展开详细列表
- 移动端单列
