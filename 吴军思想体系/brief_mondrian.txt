# 蒙德里安色块 — Creative Brief

## 概念
Piet Mondrian 的《红黄蓝构图》——黑线分割出不规则大小的红黄蓝白色块。每个色块 = 一个实体类别或重要概念。大海报式构图，不是小卡片海洋。

## 数据
- `/home/admin/mks-knowledge/吴军思想体系/data/entities.json` — 10,367 个实体
- `/home/admin/mks-knowledge/吴军思想体系/data/categories.json` — 7 个类别

## 视觉方向
- **不规则网格**：用 CSS Grid 创造 Mondrian 式构图——大大小小的矩形，黑色粗边框（6-8px solid black）
- **4 主色调**：#E3292E（红）、#F5D300（黄）、#0A4D9B（蓝）、#FFFFFF（白），加少量 #1A1A1A（黑底块）
- **7 类别各分一个大色块区域**：每个类别是一个大的 Mondrian 矩形，内部排列该类别的实体名称（像标签云，字体大小按重要性变化）
- **主角块**：7 个类别中挑最重要的实体（如"凯恩斯""牛顿""能量×信息""工业革命"）做成特大色块，像 Mondrian 的主构图焦点
- **每个色块内**：实体名称以无衬线粗体排列，颜色用互补色（红色块上白色字，黄色块上黑色字，蓝色块上白色字）
- **鼠标悬停色块**：整块微微浮起，显示类别名+实体数量
- **点击色块**：展开为该类别的全屏卡片网格

## 技术要求
- 纯 HTML+CSS+JS，单文件
- CSS Grid：`grid-template` 用命名区域，创造不规则布局
- 10,367 个实体渲染到 DOM，但按类别折叠到大色块内
- 默认视图：7 个蒙德里安大色块 + 几个焦点特写块 = ~15-20 个视觉元素
- 点击展开后显示该类别的完整实体列表
- 黑色粗边框是整个设计的灵魂——必须醒目

## 验收闸门
1. 默认视图清晰干净：~15-20 个 Mondrian 式色块，黑边框醒目
2. 4 主色调（红黄蓝白）+ 黑色边框，Mondrian 感强烈
3. 点击色块展开看到该类别的所有实体名称
4. browser_console 零报错
5. 移动端折叠为单列 Mondrian
